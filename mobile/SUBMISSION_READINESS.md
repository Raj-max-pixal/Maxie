# MAXie Mobile — Submission Readiness

## What a judge can verify

- A complete companion loop: chat, Memory Brain, companion progression, MAXie Spark, and MAXie Premium.
- Local-first memory and consent-based sharing: Spark copies only a user-selected caption.
- RevenueCat integration for offering lookup, purchase, restore, and entitlement checking.
- An honest paywall: purchase controls are enabled only after RevenueCat returns a configured offering.

## Required owner verification

1. Confirm the RevenueCat entitlement and current offering match the build configuration.
2. Use a sandbox tester to complete and record a purchase, then show “MAXie Premium active.”
3. Record Restore purchases succeeding for the same tester.
4. Build a fresh signed Android app bundle and install it on a clean device.
5. Submit the public GitHub repository, APK or app-bundle testing link, screenshots, and the 60–90 second video.
