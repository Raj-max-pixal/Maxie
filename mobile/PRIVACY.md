# MAXie Mobile Privacy

MAXie Mobile is local-first by default.

## Data on the device

The app stores companion state, settings, chat history, drafts, and Memory Brain entries on the user's device. Users can delete individual saved memories in Memory Brain.

## AI chat

When an AI provider is configured, the text a user sends to MAXie is sent to that provider to generate a response. The app keeps a local companion response mode for use without an API key.

## Sharing

MAXie Spark never posts memories, chat history, or companion data automatically. It only copies a caption after the user explicitly chooses to do so.

## Purchases

When MAXie Premium is configured, RevenueCat processes subscription entitlement information. The app checks the configured premium entitlement to decide whether Premium is active.
