## 🌟 Overview

MAXie is an intelligent AI companion designed to make your digital experience more productive, interactive, and alive. 

**Three Applications, One Repository:**

- **Desktop App** - An Electron-based desktop companion that lives on your Windows desktop
- **Mobile App** - A Flutter-based Android companion with overlay mode and smart features
- **Website** - A download and documentation hub for MAXie

MAXie understands your workflow, adapts to your routine, and becomes more personalized over time through AI-powered interactions, mood simulation, and friendship systems.

> **Create the world's most intelligent and lovable AI companion across all platforms.**

## 🚀 Installation

### Desktop Application

**Prerequisites:**
- Node.js 20+
- npm
- Windows 10/11

**Development:**
```bash
cd desktop
npm install
npm start
```

**Build:**
```bash
npm run build
```

**Package:**
```bash
npm run dist
```

### Mobile Application

**Prerequisites:**
- Flutter 3.0+
- Android Studio
- Android SDK

**Development:**
```bash
cd mobile
flutter pub get
flutter run
```

**Build APK:**
```bash
flutter build apk --release
```

### Website

**Development:**
```bash
cd website
# Open index.html in browser
```
